# i-ShowExcellence Website Concept

## Goal
Build a polished, responsive website concept that presents Benedicta Otoibhi’s verified credibility, gives Nigerian university students a clear path to support, and demonstrates a future digital student experience.

## Design
- Follow the selected kinetic dark editorial composition, refined with the chosen scholarly navy, warm white, gold, and coral palette.
- Use Instrument Serif for major editorial headlines and Work Sans for navigation and body copy.
- Use Benedicta’s supplied portrait unchanged in the hero and founder section.
- Keep motion restrained, accessible, and responsive across mobile, tablet, and desktop.

## Build
- Create the sticky navigation and all requested homepage sections in reusable React components.
- Add the interactive Academic Challenge Finder with tailored next-step recommendations.
- Build an explicitly labeled conceptual student dashboard preview.
- Use only the supplied facts and claims; label resource articles and testimonials as samples/placeholders.
- Keep social links as safe placeholders and preserve the required developer credit.

## Quality
- Add route-specific SEO and social metadata.
- Ensure semantic structure, keyboard access, image alt text, smooth scrolling, and reduced-motion support.
- Verify the live page on desktop and mobile, including navigation, interaction states, and layout integrity.
